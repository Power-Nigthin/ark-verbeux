# PixelArk 🦖

Jeu de survie en pixel art inspiré d'ARK : crée ton survivant, récolte, endors les dinos, nourris-les et apprivoise-les.
Aucune dépendance : HTML + CSS + JavaScript (canvas).

## Jouer
Ouvre `index.html` dans ton navigateur, ou publie le dépôt avec **GitHub Pages**
(Settings → Pages → branche `main`, dossier `/ (root)`).

## Création du personnage
Nom (16 caractères max), type A/B, corpulence (mince / normale / costaud, qui change les stats), coiffure, barbe, couleurs de peau, de cheveux et d'yeux, bouton Aléatoire.

## Commandes
| Action | Touche |
|---|---|
| Se déplacer | ZQSD / WASD / flèches |
| Frapper (dégâts + torpeur) / récolter arbre ou rocher | Espace |
| Lancer une fléchette tranquillisante | Clic souris |
| Nourrir un dino endormi / cueillir des baies | E |
| Baie narcotique (garde le dino endormi plus longtemps) | R |
| Fabriquer 3 fléchettes (1 bois + 1 pierre + 1 baie) | C |
| Pause | P (ou le bouton en haut à droite) |

## Dinosaures (terrestres)
Compy, Dodo, Raptor, Parasaure, Tricératops, Stégosaure, Ankylosaure, Carnotaure, Thérizinosaure, T-Rex, Giganotosaure, Diplodocus : de la taille d'un poulet à celle d'un géant. Les plus gros sont rares et résistants.

## Apprivoiser (comme dans ARK)
1. Fais monter la **torpeur** (barre violette) avec des coups ou des fléchettes jusqu'à ce que le dino s'endorme.
2. Nourris-le avec **E** : viande pour les carnivores, baies pour les herbivores. La barre verte monte.
3. Si la torpeur retombe à 0 il se réveille et tout est à refaire. Le frapper endormi fait perdre de l'efficacité.
4. Les dinos apprivoisés te suivent et combattent les sauvages.

Cycle jour/nuit, niveaux, dinos de niveau 1 à 10. Idées : monter les dinos, base, croisements, sauvegarde.
