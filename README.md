# PixelArk 🦖

Petit jeu de survie en pixel art inspiré d'ARK : récolte, fabrique des cages et capture des dinosaures.
Aucune dépendance : HTML + CSS + JavaScript (canvas).

## Jouer
Ouvre `index.html` dans ton navigateur, ou publie le dépôt avec **GitHub Pages**
(Settings → Pages → branche `main`, dossier `/root`).

## Commandes
| Action | Touche |
|---|---|
| Se déplacer | ZQSD / WASD / flèches |
| Frapper un dino / récolter arbre ou rocher | Espace |
| Fabriquer une cage (3 bois + 2 pierres) | C |
| Lancer une cage | Clic souris |

## Capturer un dino
Plus il est blessé, plus la capture a de chances de réussir. Les dinos apprivoisés te suivent et combattent les sauvages.

## Idées pour la suite
Sauvegarde (localStorage), monter les dinos, base à construire, cycle jour/nuit, nouvelles espèces dans `SP` (game.js).
